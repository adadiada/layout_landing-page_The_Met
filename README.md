# The Met Landing Page

A responsive, modern landing page designed for **The Metropolitan Museum of Art (The Met)**. The website showcases current and upcoming exhibitions, museum hours, locations, and provides visitors with an intuitive way to explore collections and plan their visit.

## Technologies Used

- **HTML5** — semantic markup and accessibility best practices
- **SCSS (Sass)** — modular styling, variables, mixins, and nested rules
- **BEM Methodology** — clean, maintainable, and scalable CSS class naming
- **CSS Grid & Flexbox** — responsive layout adapted for mobile, tablet, and desktop screens
- **JavaScript (ES6+)** — interactive burger menu, smooth scrolling, and form handling
- **Gulp / Parcel** — automated build system and local development server

## Getting Started

Follow these instructions to set up and run the project locally on your machine:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/adadiada/layout_landing-page_The_Met
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Run the project locally:**

   ```bash
   npm start
   ```

   Open (http://localhost:8080)in your browser to view the page.

## Features

- **Fully Responsive Design:** Optimized viewing experience across all devices (320px mobile, 744px tablet, and 1260px+ desktop).
- **Interactive Navigation:** Smooth anchor scrolling and an animated mobile burger menu with lock-scroll behavior.
- **Exhibition Showcase:** Grid-based gallery displaying current exhibitions with hover zoom effects and event dates.
- **Museum Info & Contact Form:** Structured visitor schedules for both museum locations (The Met Fifth Avenue & The Met Cloisters) and a validated feedback form.
